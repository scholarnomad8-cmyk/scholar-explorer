SCHOLAR EXPLORER — GLOBAL SCHOLARSHIP & CAREER HUB

এই ZIP-এ আছে:
- তোমার SE লোগো ও Discover, Learn, Lead ব্র্যান্ডিং
- দেশ, degree level, provider type এবং funding অনুযায়ী scholarship search/filter
- সরকারি/অফিসিয়াল scholarship portal links এবং তোমার Blogger articles
- Application preparation checklist
- Visa, flight, airport, dorm/accommodation, arrival, budgeting, health ও campus guide
- ৮টি subject-এর career skill roadmap ও portfolio ideas
- Mobile responsive layout

গুরুত্বপূর্ণ সীমাবদ্ধতা:
এটি একটি expanded static starter website; পৃথিবীর সব scholarship-এর complete live database নয়। বর্তমান deadline, eligibility ও funding official source থেকে যাচাই করতে হবে। Backend, admin dashboard, automatic live data feed, alerts, login এবং database এখনো নেই।

Node.js ছাড়া GitHub Pages-এ প্রকাশ:
1. ZIP extract করো।
2. GitHub.com-এ sign in করে নতুন repository বানাও।
3. index.html এবং পুরো assets folder upload করো (ZIP সরাসরি নয়)।
4. Commit changes চাপো।
5. Repository Settings > Pages > Deploy from a branch বেছে main এবং /(root) নির্বাচন করে Save করো।
6. GitHub যে URL দেবে, সেটি খুলে পরীক্ষা করো।

পরবর্তীতে global live platform করতে database, admin panel, source verification/expiry checks, duplicate detection, source URL ও last-verified date, user bookmarks/alerts এবং নির্ভরযোগ্য data integrations যোগ করতে হবে।
